	# going on in there is very, VERY messy. if you are either me from the future, looking to do a revamp of the minigame or just someone peeking at the files, remember:
	# 1. Protea is the main character of the minigame, all of the timed missions should happen to them/be seen by them, additionally, any decision that alters the minigame variables 
	# should be done ONLY in the protea decsions/timed decisions files

	# MSB decisions file is where thats located
